Image Manipulator QA fixtures

Dummy pages for running through the manual QA checklist in README.md.

  • basic.html — img / inline svg / background-image / transparent / square / tiny / huge / degenerate cases, covering most of §1–§8
  • no-image.html — a page with no images at all (§1: confirm the menu doesn't appear)
  • lazy.html — a loading="lazy" image (§10)
  • grid-7.html / grid-8.html / grid-9.html / grid-16.html — image-list 8-column grid boundary checks (§10)

Notes

  • Checking that state isn't shared across tabs (§12) just needs basic.html open in two tabs.
  • http:// / https://: served from http://localhost:8888/ via node server.mjs. This server doesn't serve https://, so that needs its own setup separately (the §0 https check is out of scope for these fixtures).
  • The file:// case (§0) can be checked with the same content by opening each HTML file in this directory directly from disk.
  • WebP (§4 File type) wasn't generated — no local encoder was available.
  • Localization (§13) needs no HTML-side support — check by switching Chrome's language setting.

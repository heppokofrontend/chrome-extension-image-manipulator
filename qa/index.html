Image Manipulator QA fixtures

Dummy pages for running through the manual QA checklist in README.md.

  • basic.html — img / inline svg / background-image / transparent / square / tiny / huge / degenerate cases
  • no-image.html — a page with no images at all
  • lazy.html — a loading="lazy" image

Notes

  • Checking that state isn't shared across tabs (§3) just needs basic.html open in two tabs.
  • The file:// case (§0) can be checked with the same content by opening each HTML file in this directory directly from disk.
  • Localization (§4) needs no HTML-side support — check by switching Chrome's language setting.
  • Recommended: also run through a basic pass in an Incognito window (enable "Allow in Incognito" for the extension first via chrome://extensions — it's off by default, so this catches gaps that only show up there).
